# NIP drafts

Drafts and specs of Nostr protocol extensions that TOON apps use, kept here until (and
unless) they are proposed upstream. One file per NIP, named for its number or its subject
(for example the NIP-34 git-objects-on-Blossom draft, and NIP-C1).

A NIP here describes **wire shapes**: event kinds, tags and their meaning. How the relay
reads them, or what it serves, is a decision and belongs in [`../adr/`](../adr/README.md).
How to author or read one app's events for people and skills is a guide and belongs in
[`../apps/`](../apps/README.md).
