# App guides

One protocol guide per Nostr app type the relay serves a UI for (`git.md` for
NIP-34 repos at `/repo`, `social.md` for the social NIPs, repos first, at
`/social`): the events involved, how to publish them, and where the UI
shows them. Skills and other tools link to these.

A guide explains; it does not decide. The wire shapes are in [`../nips/`](../nips/README.md)
and the decisions behind the relay's behaviour are in [`../adr/`](../adr/README.md).
